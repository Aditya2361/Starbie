# ⭐ Starbie

**Starbie** is a tiny motion-controlled digital pet, basically a desktop Tamagotchi with minimal gameplay buttons. Instead of pressing controls, you interact with Starbie by physically moving the board.

## 🔧 Hardware

The Starbie board includes:

* Microcontroller: Seeed Studio XIAO ESP32-C3 
* Display: 0.96 Inch Generic Screen
* Motion sensor: MPU 6050
* Environmental sensor: DHT 11
* Compact PCB: JCL PCB
* MX Switches
* Resistor

## 🎮 How It Works

Instead of mainly using buttons to control Starbie, you interact with it by **moving the physical board**.

You can:

* Tilt the board
* Move the board
* Check in on your pet
